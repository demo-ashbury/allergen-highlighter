# Allergen Highlighter

A small demo tool that highlights the 14 UK allergens in an ingredients list, shown in bold as required on pack.

- `index.html` — the page
- `allergens.js` — the allergen list and detection logic
- `allergens.test.js` — tests, run with `node --test` (Node 20+, no install needed)

Changes go through pull requests. Tests run automatically on every pull request.
